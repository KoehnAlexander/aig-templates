\section{Introduction}
Reasoning under uncertainty is a classical problem in artificial intelligence. Several approaches have been proposed to address this issue, including possibility theory \cite{halpern1990}, fuzzy logic \cite{zadeh1965}, and possibilistic logic \cite{dubois1991}. The starting point of possibility theory was by Zadeh in 1978 \cite{zadeh1978} as an extension of fuzzy set theory \cite{zadeh1965}. The goal was to provide a qualitative framework for handling uncertain information. Building upon Zadeh’s work, Dubois and Prade formulated possibilistic logic \cite{dubois1991} to integrate possibility theory into formal logic systems. \\
Possibilistic logic has been extended for different applications such as default reasoning, belief revision, or decision-making under uncertainty with generalized approaches; see \cite{dubois2017generalized}. The goal of this paper is to introduce basic possibilistic logic with examples and visualizations. In this paper, we will focus on basic possibilistic logic. \\
This work is structured as follows. In Section \ref{Fundamentals}, basic possibilistic logic is explained, including a short notice about key aspects of possibility theory. Before the core part of this paper, Section \ref{DifferencesClassical} compares possibilistic logic with classical logic, and Section \ref{RelationAI} discusses the relationship of this logic with artificial intelligence. Section \ref{Examples} will go through the penguin problem example with this logic. Section \ref{Conclusion} summarizes and discusses the results of this paper.
\section{Fundamentals of Basic Possibilistic Logic} \label{Fundamentals}
The following introduction to basic possibilistic logic is inspired by the presentation of Dubois and Prade \cite{dubois2014possibilistic}. This section provides a brief overview of basic possibilistic logic. For more details, we refer to the works \cite{dubois2014possibilistic} and \cite{dubois1991}. \\
In this section, we first introduce the main concepts of possibility theory, which are necessary for understanding possibilistic logic. Then, we present basic possibilistic logic, covering its syntax, axioms, inference rules, and semantic aspects.
\subsection{Possibility Theory}
Possibility theory is explained in detail in \cite{dubois2023possibility} and \cite{zadeh1978}. It relies on the concept of possibility distributions.
\begin{definition}
	A possibility distribution is a function \( \pi \) that maps elements from a set of states \( U \) to a totally ordered scale \( \left[ 0 , 1 \right]  \), see \cite{dubois2014possibilistic}:
	\[
	\pi: U \to \left[ 0 , 1 \right] .
	\]
\end{definition}
The value $ \pi(u) $ indicates the degree of possibility assigned to the state u. This function represents the agent’s knowledge and helps differentiate between states that are more or less plausible. A state u is considered impossible if $ \pi(u) = 0 $, whereas it is fully possible if $ \pi(u) = 1 $.
\begin{example}
	Consider a weather forecasting scenario where an agent assesses the possibility of different weather conditions for tomorrow. Let $ U = \{\text{sunny}, \text{cloudy}, \text{rainy}, \text{stormy}\} $ be the set of possible states. The agent assigns a possibility distribution $ \pi $ as follows: \\
	$ \pi(\text{sunny}) = 1, \quad \pi(\text{cloudy}) = 0.7, \quad \pi(\text{rainy}) = 0.3, \quad \pi(\text{stormy}) = 0$. \\
	The agent is completely certain that a sunny day is fully possible ($\pi(\text{sunny}) = 1$), considers cloudy weather strong possible ($\pi(\text{cloudy}) = 0.7$), finds rain unlikely ($\pi(\text{rainy}) = 0.3$), and states a storm impossible ($\pi(\text{stormy}) = 0$).
\end{example}
The basic measures of Possibility theory models with the two measures, possibility and necessity, the occurence of an event (see \cite{dubois2014possibilistic}, \cite{lang2000possibilistic}).
\begin{definition}  
	The possibility of an event \( A \) is defined as:  
	\[
	\Pi(A) = \sup_{u \in A} \pi \left( u \right).
	\]  
\end{definition}  
The possibility measure represents the maximum possibility assigned to any state in \( A \). It shows the degree to which \( A \) is consistent with \( \pi \). Possibility measures fulfill the maxitivity property:
\[
\Pi \left( A \cup B \right)  = \max \left( \Pi \left( A \right), \Pi \left(  B \right) \right).
\]  
\begin{definition}  
	The necessity of an event \( A \) is defined as:  
	\[
	N(A) = \inf_{u \notin A} \left( 1 - \pi \left( u \right) \right).
	\]  
\end{definition}  
The necessity measure represents the minimum of the inverted possibility values of all states not in \( A \). It evaluates the extent to which \( A \) is certainly implied by \( \pi \). Necessity measures satisfy the characteristic minimization property:  
\[
N \left( A \cap B \right)  = \min \left( N \left( A \right) , N \left( B \right) \right).
\]  
This property expresses that for \( A \cap B \) to be certain, both \( A \) and \( B \) must be certain individually.  
The duality between these two measures is given by:  
\[
N \left( A \right)  = 1 - \Pi \left( A^c \right),
\]  
where \( A^c \) is the complement of \( A \).  
\begin{example}
	Consider a possibility distribution $ \pi $ over a set of possible weather conditions: $ U = \{ \text{sunny}, \text{cloudy}, \text{rainy} \} $ with the values $ \pi(\text{sunny}) = 1 $, $ \pi(\text{cloudy}) = 0.7 $, and $ \pi(\text{rainy}) = 0.3 $. \\
	The possibility of the event "not rainy" $ A = \{ \text{sunny}, \text{cloudy} \} $ is given by: 
	\[
	\Pi(A) = \sup_{u \in A} \pi(u) = \max(\pi(\text{sunny}), \pi(\text{cloudy})) = \max(1, 0.7) = 1.
	\]
	The necessity of "not rainy" is computed as:
	\[
	N(A) = \inf_{u \notin A} (1 - \pi(u)) = 1 - \pi(\text{rainy}) = 1 - 0.3 = 0.7.
	\]
	This means that the event "not rainy" is fully possible but not completely necessary.
\end{example}
\subsection{Formal Foundations of Basic Possibilistic Logic}
This section introduces the foundations of basic possibilistic logic. First, the syntax is presented. Second, the semantic aspects of the logic are derived. Third, the inference rules are explained. Finally, the axioms of this logic are covered. Further references for this section are \cite{dubois2014possibilistic}, \cite{hollunder1995alternative}.
\begin{definition}  
	The syntax of a basic possibilistic logic formula is:  
	\[
	(a, \alpha)
	\]  
	where \( a \) is a classical logic formula (e.g., \( p \to q \)) and \( \alpha \) is the certainty level (the minimum necessity degree of \( a \)). The classical logic formula can be from propositional logic or first-order logic (see \cite{dubois2014possibilistic}).  
\end{definition}  
The semantics of a possibilistic logic formula are based on the semantics of the corresponding classical logic formula. The pair \( \left( a , \alpha \right) \) is interpreted as \( N \left( a \right) > \alpha \), meaning that the formula \( a \) is at least certain to degree \( \alpha \). The higher the value of \( \alpha \), the stronger the belief in \( a \).  
\begin{example}  
	\((b \to f, 0.9)\) means that "birds fly" holds with certainty \( 0.9 \).  
\end{example}
The following inference rules of basic possibilistic logic are necessary for the application of the logic in this paper. The \textit{certainty weakening rule} states that if a formula holds with a certainty level \( \alpha \), it also holds with any lower certainty level \( \beta \) because we are being less demanding (see Equation \ref{Eq:Certainty_weakening}).
\begin{equation} \label{Eq:Certainty_weakening}
	\text{If } \beta \leq \alpha, \quad (a, \alpha) \vdash (a, \beta)
\end{equation}
The \textit{modus ponens rule} states that if \( a \to b \) holds with certainty level \( \alpha \), and \( a \) also holds with certainty level \( \alpha \), then \( b \) must hold with certainty level \( \alpha \) (see Equation \ref{Eq:Modus_ponens}).
\begin{equation}\label{Eq:Modus_ponens}
	(\neg a \lor b, \alpha), (a, \alpha) \vdash (b, \alpha), \quad \forall \alpha \in (0, 1]
\end{equation}  
In classical logic, the \textit{resolution rule} allows us to combine two clauses that share a literal, eliminating that literal and inferring a new clause. In possibilistic logic, the resolution rule preserves the certainty level \( \alpha \) since the inferred formula \( b \lor c \) cannot be more certain than the least certain premise (see Equation \ref{Eq:Resolution}).
\begin{equation}\label{Eq:Resolution}
	(\neg a \lor b, \alpha), \quad (a \lor c, \alpha) \vdash (b \lor c, \alpha)
\end{equation}
The \textit{weakest link resolution rule} extends the resolution rule by considering different certainty levels \( \alpha \) and \( \beta \). It reflects the idea that the certainty of the conclusion cannot exceed the weakest certainty of the premises (see Equation \ref{Eq:Weakest_link_resolution}).
\begin{equation}\label{Eq:Weakest_link_resolution}
	(\neg a \lor b, \alpha), \quad (a \lor c, \beta) \vdash (b \lor c, \min(\alpha, \beta))
\end{equation}
For inference with basic possibilistic logic, a possibilistic logic base is used.  
\begin{definition}  
	A possibilistic knowledge base is a collection of possibilistic formulas:  
	\begin{equation}\label{Eq:Knowledge_base}  
		\Gamma = \{(a_i, \alpha_i), i = 1, \dots, m\}  
	\end{equation}  
\end{definition}  
\begin{example} \label{example:medical}  
	In a medical diagnosis system symptoms are associated with diseases with varying degrees of certainty. The possibilistic knowledge base is given by:  
	\[
	\Gamma = \{ (\text{Fever} \Rightarrow \text{Flu}, 0.9), (\text{Cough} \Rightarrow \text{Cold}, 0.7), (\text{Headache} \Rightarrow \text{Migraine}, 0.8) \}.
	\]  
	This means that having a fever strongly suggests flu with a certainty level of 0.9, a cough suggests a cold with 0.7, and a headache leads to a migraine with 0.8.  
\end{example}
The \( \alpha \)-cut of a knowledge base contains only those formulas with a certainty level of at least \( \alpha \). It has a nested structure where \( \Gamma_\alpha \) is a subset of \( \Gamma_\beta \) if \( \alpha \geq \beta \).
\begin{definition}  
	The \( \alpha \)-cut of a knowledge base is defined as:  
	\begin{equation}\label{Eq:Knowledge_base_cut}  
		\Gamma_\alpha = \{(a_i, \alpha_i) \in \Gamma \mid \alpha_i \geq \alpha\}  
	\end{equation}  
\end{definition}
\begin{example}  
	Continuing with Example \ref{example:medical}, the \( \alpha \)-cut of the knowledge base for \( \alpha = 0.8 \) is:  
	\[
	\Gamma_\alpha = \{ (\text{Fever} \Rightarrow \text{Flu}, 0.9), (\text{Headache} \Rightarrow \text{Migraine}, 0.8) \}.
	\]
\end{example}
A possibilistic inference \( (a, \alpha) \) depends only on formulas with certainty levels \( \geq \alpha \), as shown in Equation \ref{Eq:Inference}:
\begin{equation}\label{Eq:Inference}  
	\Gamma \vdash (a, \alpha) \iff \Gamma_\alpha \vdash (a, \alpha)  
\end{equation}
An important property of knowledge bases is their inconsistency level.
\begin{definition}  
	The inconsistency level of a knowledge base \( \Gamma \) is defined as:  
	\begin{equation}\label{Eq:Inconsistency_level}  
		\text{inc-l}(\Gamma) = \max\{\alpha \mid \Gamma \vdash (\bot, \alpha)\}  
	\end{equation}  
	where \( \bot \) represents an inconsistent state in logic.  
\end{definition}
The inconsistency level represents the highest certainty level at which the knowledge base becomes inconsistent. Any formula with a certainty level higher than the inconsistency level remains free from inconsistency.
\begin{example}  
	In the above example, there are no conflicting statements (e.g., one rule stating “Fever implies Flu” and another stating “Fever does not imply Flu”). The inconsistency level \( \text{inc-l}(\Gamma) \) is 0, indicating that the knowledge base is fully consistent at all certainty levels.  
\end{example}
\section{Differences from Classical Logic} \label{DifferencesClassical}  
Possibilistic logic extends classical logic by adding a certainty degree into classical logic formulas, see \cite{dubois2014possibilistic}. In classical logic, a statement is either true or false, corresponding to a binary value system. In contrast, in possibilistic logic, the certainty degree of a possibilistic formula is a non-binary value \cite{dubois1991}. \\
In classical logic, the presence of a contradiction makes the entire knowledge base invalid, allowing any formula to be derived. In difference possibilistic logic can handle inconsistency. The inconsistency degree of a knowledge base reflects the extent to which it is contradictory \cite{dubois2014possibilistic}. This feature makes possibilistic logic robust for reasoning in incomplete and inconsistent environments.
\section{Relation to Artificial Intelligence} \label{RelationAI}
Possibilistic logic, with its strength in modeling certainty and handling inconsistency, has various application fields in artificial intelligence problems \cite{dubois2014possibilistic}, \cite{2021possibility}. The following apllication examples do not fully cover every application field. In default reasoning, possibilistic logic handles incomplete information reasoning. Additionally, possibilistic logic can be applied in information fusion, where knowledge is combined from different sources. The logic can also assist with decisions under uncertainty. One application is its use in medical diagnosis problems \cite{grabisch2003}. In \cite{dubois2020possibilistic}, \cite{persia2023learning}, connections between reasoning with possibilistic logic and machine learning are explored.
\section{Applying Basic Possibilistic Logic} \label{Examples}  
This section will go through the penguin problem example in detail with additional visualization at key points. This example was already presented in the context of possibilistic logic in \cite{dubois2014possibilistic}, \cite{prade1992representing} and this paper is inspired these papers, but gives more details at important sections of the example. This example is well suited for showing the behavior of possibilistic logic as the handling of inconsistencies is needed for finding answers.
\subsection{Default Rules}  
The knowledge base of this example consists of three default rules about birds and penguins. A default rule expresses general knowledge and holds in most cases, but it might have exceptions:  
\begin{align*}
	d_1 &: b \rightarrow f \quad (\text{"Birds fly"}), \\
	d_2 &: p \rightarrow \neg f \quad (\text{"Penguins do not fly"}), \\
	d_3 &: p \rightarrow b \quad (\text{"Penguins are birds"}).
\end{align*}  
In the following, the goal is to assign certainty levels to these rules to create a possibilistic knowledge base. After the creation of the possibilistic knowledge base we are able to use it for reasoning. To construct this knowledge base, the following steps are necessary. First, the constraints from the rules are derived. Second, the possible worlds are ranked based on these constraints. Finally, using the ranked worlds, the certainty levels of the rules are determined.
\subsection{Constraints}
From the default rules, a set of comparative possibility constraints can be constructed. Comparative possibility constraints are derived from the idea that a rule \( a \rightarrow b \) implies that situations where both \( a \) and \( b \) hold should be considered more possible than those situations where \( a \) holds but \( b \) does not, see \cite{dubois2014possibilistic}:  
\begin{align*}
	C_1 &: b \land f >_\Pi b \land \neg f \quad \text{(birds fly)}, \\
	C_2 &: p \land \neg f >_\Pi p \land f \quad \text{(penguins do not fly)}, \\
	C_3 &: p \land b >_\Pi p \land \neg b \quad \text{(penguins are birds)}.
\end{align*}  
For example, \( C_1 \) states that the worlds where birds fly are more possible than worlds where birds do not fly. These constraints establish an ordering over possible worlds, which will be examined next.  
\subsection{Possible Worlds}
The propositional language for this example involves three propositions: \( b \) (bird), \( p \) (penguin), and \( f \) (flies). The set of possible worlds, \( \Omega \), consists of all possible combinations of \( (b, f, p) \) represented by \( \omega_i \):
\begin{align*}
	\Omega = \{ \omega_0, \omega_1, \omega_2, \omega_3, \omega_4, \omega_5, \omega_6, \omega_7 \}.
\end{align*}  
Based on the constraints, these worlds are ranked to reflect which interpretations are more plausible.\\

In Table \ref{tab:worlds_rules}, each row represents a world with a unique combination of the three predicates, along with an indication of whether the default rules are satisfied or violated. No world satisfies all rules, highlighting the core reasoning challenge. The worlds \( \omega_0 \) and \( \omega_2 \) neither satisfy or violate any rule.  
The first default rule, \( d_1: b \rightarrow f \) ("Birds fly"), increases the plausibility of worlds where birds fly (\( b \land f \)) compared to those where birds do not fly (\( b \land \neg f \)). This rule influences the ranking between worlds \( \omega_6 \), \( \omega_7 \) (where the bird flies) and \( \omega_4 \), \( \omega_5 \) (where the bird does not fly).
The second default rule, \( d_2: p \rightarrow \neg f \) ("Penguins do not fly"), prioritizes worlds where penguins do not fly (\( p \land \neg f \)) over those where penguins fly (\( p \land f \)). This affects the relative plausibility of \( \omega_5 \), \( \omega_1 \) (where the penguin does not fly) compared to \( \omega_7 \), \( \omega_3 \) (where the penguin flies).  
The third default rule, \( d_3: p \rightarrow b \) ("Penguins are birds"), ranks the worlds \( \omega_5 \), \( \omega_7 \) higher than \( \omega_1 \), \( \omega_3 \).
By incorporating these rules, we derive the following constraints on possibility degrees:  
\begin{align*}
	C_1 &: \max(\pi(\omega_6), \pi(\omega_7)) > \max(\pi(\omega_4), \pi(\omega_5)), \\
	C_2 &: \max(\pi(\omega_5), \pi(\omega_1)) > \max(\pi(\omega_3), \pi(\omega_7)), \\
	C_3 &: \max(\pi(\omega_5), \pi(\omega_7)) > \max(\pi(\omega_1), \pi(\omega_3)).
\end{align*}
These constraints guide the ranking of possible worlds according to their plausibility in the given possibilistic logic framework.

By following the constraints, we determine the ranking of the worlds as follows:  
\begin{align*}
	\pi(\omega_0) &= \pi(\omega_2) = \pi(\omega_6) = 1, \\
	\pi(\omega_4) &= \pi(\omega_5) = \frac{2}{3}, \\
	\pi(\omega_1) &= \pi(\omega_3) = \pi(\omega_7) = \frac{1}{3}.
\end{align*}
In this example, we use numerical values to represent the different qualitative possibility levels of the worlds. The worlds \( \omega_0 \) and \( \omega_2 \) hold the highest possibility level since no constraints downgrade them.  
\subsection{Creating Knowledge Base}
We calculate the necessity degrees from the possibility of the worlds as follows with the duality relationship of possibility and necessity:
\begin{align*}
	N(\neg p \lor \neg f) &= \min \{ 1 - \pi(\omega) \mid \omega \models p \land f \} \\
	&= \min(1 - \pi(\omega_3), 1 - \pi(\omega_7)) = \frac{2}{3} \\
	N(\neg b \lor f) &= \min \{ 1 - \pi(\omega) \mid \omega \models b \land \neg f \} \\
	&= \min(1 - \pi(\omega_4), 1 - \pi(\omega_5)) = \frac{1}{3} \\
	N(\neg p \lor b) &= \min \{ 1 - \pi(\omega) \mid \omega \models p \land \neg b\} \\
	&= \min(1 - \pi(\omega_1), 1 - \pi(\omega_3)) = \frac{2}{3}
\end{align*}
Thus, we obtain the possibilistic knowledge base:
\[
K = \{ (\neg p \lor \neg f, \frac{2}{3}), (\neg p \lor b, \frac{2}{3}), (\neg b \lor f, \frac{1}{3}) \}.
\]

	\label{fig:rules_ranking}

\subsection{Reasoning with Uncertain Information}
In this section, we determine whether Tweety flies by introducing relevant information about itself. First, we introduce that Tweety is a bird:
\begin{align*}
	F = \{ (b, 1) \} \quad \text{(Tweety is a bird with certainty 1)}.
\end{align*}
Using the rule $(\neg b \lor f, 1/3)$ from the knowledge base $K$, we apply the weakest link resolution rule (Equation \ref{Eq:Weakest_link_resolution}):
\begin{align*}
	(\neg b \lor f, 1/3) \quad \text{and} \quad (b, 1) \vdash (f, \min(1, 1/3)) = (f, 1/3).
\end{align*}
Thus, we conclude that Tweety flies with a certainty level of $\frac{1}{3}$. The result is illustrated graphically in Figure \ref{fig:firstinformation}. The violet arrow symbolizes the inference using the weakest link resolution rule.
\begin{figure}[h]
	\centering

		\draw[->] (-2,-4) -- (-2,4.5) node[right] {Certainty Level};

		\draw[draw=none, thick, fill=blue, opacity=0.1] (-2,-1.5) node[above right] {$\frac{2}{3}$} rectangle (6,1.5);
		\draw[draw=none, thick, fill=red, opacity=0.1] (-2,1.5) node[above right] {$1$} rectangle (6,4);
		% Nodes
		\node [draw] (f1) at (2,3) {$ b, 1$};

		\node [draw] (c2) at (4,0) {$\neg p \lor b, \frac{2}{3}$};
		\node [draw] (c3) at (2,-3) {$\neg b \lor f, \frac{1}{3}$};
		
		\draw[->, violet, thick] (f1) -- (c3);
		
		\draw[very thick, dashed, red] (-2,-4) -- (6,-4) node[right] {Inconclusive Level};
	\end{tikzpicture}
	\caption{Possibilistic knowledge base of the penguin problem with first information about Tweety}
	\label{fig:firstinformation}
\end{figure}

If we introduce new information stating that Tweety is also a penguin:
\begin{align*}
	F = \{ (b,1), (p,1) \} \quad \text{(Tweety is a penguin with certainty 1)},
\end{align*}
then, using $(\neg p \lor \neg f, 2/3)$ with the weakest link resolution rule, we derive:
\begin{align*}
	(\neg p \lor \neg f, 2/3) \quad \text{and} \quad (p, 1) \vdash (\neg f, \min(1, 2/3)) = (\neg f, 2/3).
\end{align*}
Since this results in conflicting conclusions:
\begin{align*}
	(\neg f, 2/3) \quad \text{and} \quad (f, 1/3) \vdash (\bot, \min(2/3, 1/3)) = (\bot, 1/3),
\end{align*}
the system detects an inconsistency of level $\frac{1}{3}$. Given the principle that higher certainty information takes advantage, the inference that Tweety flies is overridden, leading to the final conclusion:
\begin{align*}
	K \cup F \vdash (\neg f, 2/3),
\end{align*}
which means "Tweety does not fly" with a certainty of $\frac{2}{3}$.  
The results are illustrated in Figure \ref{fig:secondinformation}. It can be seen that the inconclusive level is raised to a level where no conflict exists between the information.

This example shows how possibilistic logic can handle inconsistency when new information is added. The creation of the possibilistic knowledge base with qualitative certainty levels out of the relation between the constraints is one major aspect of this example.

\section{Discussion and Conclusion} \label{Conclusion}
This paper introduced basic possibilistic logic and showed its application through the penguin problem example. It is presented how possibilistic logic extends classical logic by adding certainty levels to logical formulas, allowing for reasoning under uncertainty and inconsistency. In the penguin problem possibilitic logic handled inconsistency in the knowledge base, which was created out of the constraints of the problem. The key learning of the example and this paper is that possibilistic logic provides a robust framework when inconsistent information are present.
